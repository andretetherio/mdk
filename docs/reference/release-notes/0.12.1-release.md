# Release v0.12.1

## Overview

v0.12.1 is a patch release. It moves the UI's form stack to zod 4, replaces the in-repo font package with a regular npm
dependency, and clears four high-severity advisories published after v0.12.0.

## Breaking changes

**`@tetherto/mdk-react-devkit` peers on zod 4.** The peer dependencies move to `zod` `^4.6.6`, `@hookform/resolvers` `^5.9.2`
and `react-hook-form` `^7.55.0`. The devkit's validators and schemas keep their signatures and messages; an app with its own
zod schemas follows the zod 4 migration.

**`@tetherto/mdk-fonts` is removed.** Declare JetBrains Mono from `@fontsource-variable/jetbrains-mono` instead, as the catalog
and the UI shell template do. The migration steps for both changes are in [`CHANGELOG.md`](../../../CHANGELOG.md).

## What's new

**Lighter monospace font**: one variable JetBrains Mono file per script covers every weight, about 40 KB for Latin, and weight
800 renders as a real weight.

## Removed

**`@tetherto/mdk-fonts`**: the font now comes from npm.

## Fixed

**Security**: zod, happy-dom, undici and body-parser move to patched versions (GHSA-mrhx-c7xc-m3w5, GHSA-834v-8h66-3h79,
GHSA-xjj6-f33q-929c, GHSA-27r3-jxmh-p828).
